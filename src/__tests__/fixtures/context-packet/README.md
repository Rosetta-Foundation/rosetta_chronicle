# Synthetic context-packet fixtures

Invented ChatGPT-shaped records for lexical packet tests. Names, dates,
IDs, and text are synthetic. No private corpus content.

Logical case IDs (P1–P4, D1–D4, T1, S1, C1, R1, F1–F4) are defined in
`expected-results.json`. Runtime hashes are computed by the test helper;
do not hard-code fake hashes.
